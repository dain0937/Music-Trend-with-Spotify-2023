# Spotify-2023-Analysis 🎶

## 📌 Overview

This project explores music trends using the **Spotify Top Songs 2023** dataset. It analyzes streaming popularity, artist performance, and audio features like tempo, danceability, and energy — offering insight into what made songs popular in 2023.

## 🛠️ Tools

- **Python**
- Libraries: `pandas`, `matplotlib`, `seaborn`, `numpy`

## 📊 Key Analyses

- **Top 10 Songs** by streams (e.g., *Blinding Lights*, *Shape of You*)
- **Top Artists**: The Weeknd, Taylor Swift, Ed Sheeran
- **Audio Features**: BPM, danceability, energy
- **Monthly Trends** in features like valence, acousticness, and energy

## 🔍 Insights

- Popular songs trend toward high **danceability (~70–80%)** and **energy (~65%)**
- Streaming success often tied to strong **audio feature profiles**
- Popular songs were released **throughout the year**, not just in peak seasons
